# Roadmap

Abhakbar. Etwas zählt erst, wenn ein Mensch es auf dem Tablet tun kann.

## Phase A — Kern verriegeln

- [x] Arbeit in kurzen Sätzen, dieselben Wörter
- [x] Lebensraum gegen Geopolitik gehalten (Kapitel 5)
- [x] Norman nur gegen die Verwechslung
- [x] Inhaltsverzeichnis, Sprungmarken, Skip-Links
- [x] Lesen / Teilen / GitHub, Canonical-Domain
- [x] Literatur knapp und ehrlich, keine Scheinzitate
- [x] Druck / Reader / PDF ohne Browser-Chrome
- [x] Fokus, Tastatur, Screenreader der Arbeit geprüft
- [ ] Kontrast und Ziele ≥ 44px auf 390px geprüft

Akzeptanz: Jemand ohne Gibson-Vorkenntnis versteht Angebot, Umwelt, Lebensraum. Die Arbeit ist ausdruckbar und zitierbar.

## Phase B — Feld als Methode

- [x] Drei Schalter ändern die Marken (erste Studio-Liste)
- [x] Nah kartesisch, weit log-polar
- [x] Horizon-Collapse, Gaze-Strip
- [x] Bäckerei als Bestand (Lehrfall, erste Fassung)
- [x] Wohnung / Haus / Hof / Venloer vollständig
- [x] Live-Uhr als Default, Zeitregler zum Prüfen
- [x] Lage (Hunger, Satt, Müde, Termin) ändert das Ranking
- [x] Inspector: Was. Für wen. Warum jetzt. Was man tun müsste.
- [x] Feld-Zustand in der URL, Canonical bleibt
- [x] Eigene Mitte lokal anlegen und speichern

Akzeptanz: Umweltwechsel ändert Blick, Marken, Inspector, Bestände. Kapitel 7 ist in unter einer Minute sichtbar.

## Phase C — Drei Umwelten ernst

- [x] Studio: erste getrennte Listen
- [x] Jeder Locus: eigene Angebote je Umwelt (Park/Dom noch dünn)
- [x] Roboter ohne Anthropomorphismus
- [x] Entwickler: Anschlüsse, nicht Stimmung
- [x] Kein gemeinsames Inventar als Wahrheit

Akzeptanz: Nach dem Wechsel wird eine gemeinsame Liste unruhig. Dose und Schalter sind nie dieselbe Marke.

## Phase D — Verdrahtung

- [x] Haus-Adapter, umweltgetrennt, simuliert
- [x] Bestand-Adapter (Bäckerei vollständig, zweiter Ort derselben Logik)
- [x] Gehen: Horizont, Fuß zuerst, Bahn als Angebot
- [x] Modell-Vertrag: wer fragt, welche Umwelt, welcher Radius, welche Zeit, welche Lage
- [x] Apparat: Pfad nur auf Roboter-Angeboten, Grenzen sichtbar
- [x] `Affordance` ohne `umwelt` gilt als Fehler, sobald sie Gemeinsamkeit behauptet

Akzeptanz: Fünf Schnitte sind benutzbar und dokumentiert. Keine Geräte-App.

## Phase E — Täglicher Gebrauch

- [x] Onboarding in 60 Sekunden
- [x] Editor: Locus, Angebot, Verb, Dimension, Sichtbarkeit, Schritt, Bestand, Umwelt
- [x] Import/Export JSON der Theorie
- [ ] Offline-Lesen der Arbeit
- [ ] Feld mit letztem Atlas offline

Akzeptanz: Pedda trägt die eigene Mitte ein, ohne uns.

## Phase F — Öffentliche Reife

- [x] Production-Build grün
- [x] Tests: Umweltfilter, Ranking, Share-URL, Radius, Zeit/Bestand
- [x] README wie die Arbeit
- [x] Ehrliche Lücken, leere Zustände
- [x] Datenschutz: nichts heimlich senden
- [ ] a11y hält, während das Feld dichter wird (390px noch ungemessen)

## Phase G — Tiefe, nicht Breite

Nur wenn A–F stehen und der Kern es verlangt.

- [ ] Drei Umwelten nebeneinander
- [ ] Zeitraffer eines Bestands
- [ ] Forschungsfilter Gibson / Uexküll / Lewin
- [ ] Export einer Verdrahtungs-Spec
- [ ] Audio / Lage / AR nur wenn der Standpunkt schärfer wird

## Maxed out

- [ ] Die Arbeit ist auf einem Tablet eine der klarsten öffentlichen Erklärungen von Angebot, Umwelt, Lebensraum

- [ ] Umweltwechsel ändert Blick, Marken, Inspector, Bestände

- [ ] Ein Fremder kann die eigene Mitte anlegen und speichern
- [ ] Adapter-Grenzen für Haus, Bestand, Gehen, Modell, Apparat — umweltgetrennt, dokumentiert, simuliert benutzbar
- [ ] Production unter peddavommond.de/moeglichkeitensystem ist die Wahrheit
- [ ] Lesen, Teilen, GitHub stimmen
- [ ] a11y, Mobile, Build, Tests der Kernlogik halten
